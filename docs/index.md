# SciTech.Rpc

SciTech.Rpc is a high-performance, code-first remote procedure call framework for .NET. Services are defined by
attributed interfaces in code, and can be called over the Lightweight communication layer (TCP, named pipes or
in-process) or over gRPC.

* For an overview and getting started, see the [README](https://github.com/SciTechSoftware/SciTech.Rpc#readme).
* [Exception handling](exception-handling.md): declared faults and exception converters.
* [Lightweight protocol](lightweight-protocol.md): the wire format of the Lightweight communication layer.
* [API reference](api/index.md).
